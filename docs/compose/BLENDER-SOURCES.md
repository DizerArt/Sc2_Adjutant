# Исходники BRAT_OK в Blender

Редактируемый комплект находится в [art/blender/brat-ok-loading](../../art/blender/brat-ok-loading/README.md).
Это общий loading-хоровод v3, библиотека 53 букв и шесть отдельных проектов
юнитов/фона. Восемь `.blend` упакованы с нужными изображениями и шрифтом;
отдельного подключения к исходному StarCraft Adjutant не требуется.

Вместе перенесены исходная прорисовка, PNG букв/метрики, prompts, исторические
build/update/verify helpers и отчёты. Исполняемые переносимые инструменты отделены
от исторических `.py.txt`; последние содержали машинные пути и иногда сохраняли
проект даже при «verify». Прочитайте основной README перед запуском.

Проверено 01.11.2026 на Blender 5.2.2 LTS:

- исходные файлы не изменены, SHA256 зафиксированы в migration-sources.json;
- все восемь проектов открыты из другой папки с кириллицей;
- внешних библиотек/неупакованных изображений/шрифтов нет;
- параметры сцен и контрольные суммы кривых анимации сохранены после переоткрытия;
- неиспользуемые исторические datablocks сохранены через fake users;
- пробный кадр 960×540 и буква A 511×557 совпали с прежними PNG по всем RGBA;
- вывод отчётов/PNG ограничен renders/, audit не может перезаписать .blend;
- исходный scripts/check.ps1: 673 Python / 130 Node PASS, 2 прежних warnings.

Полный свежий 576-кадровый рендер и экспорт всех 53 букв при переносе не выполнялись.
Сохранены прежние конечные PNG и исторические отчёты. Независимый source review
проверил переносимые инструменты и границы записи; замечания исправлены.

Этот пакет не добавляет Blender или Python в зависимости установленного приложения,
не меняет текущий GIF оверлея и не возобновляет разработку шортсов. Пакет намеренно
не входит в NSIS: это инструменты автора оформления, а не runtime-ресурсы.
