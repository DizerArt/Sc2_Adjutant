# Установка Compose на Windows

Локальная сборка установщика: `02_application/release/compose-installer/`.
Запустить `SC2 Adjutant Compose_1.1.11_x64-setup.exe`, выбрать язык и каталог,
завершить установку. Приложение доступно через меню «Пуск». Это текущая
экспериментальная Compose-сборка; оставшиеся ограничения перечислены в STATUS.md.

Windows x64, установка для текущего пользователя, без обязательного повышения прав.
По умолчанию файлы приложения размещаются в `%LOCALAPPDATA%/SC2 Adjutant Compose`.
SQLite/настройки/кеш — отдельно, в `%APPDATA%/com.dizerart.sc2companion.compose/data`.
Существующая Electron-версия SC2 Adjutant имеет отдельную установку и профиль.
Пользовательский SC2_ASSISTANT_DATA_DIR, если задан, переопределяет профиль.

Установщик содержит карты, OBS HTML, встроенный Node и остальные текущие ресурсы.
Устанавливать Node, Rust, Python или Docker для запуска не требуется. Нужен
WebView2: при его отсутствии установщик скачивает bootstrapper Microsoft и
устанавливает runtime; в этом случае требуется интернет. Набор голосовых моделей
равен ресурсам сборки; новые модели автоматически не скачиваются.

Перед обновлением полностью завершить Compose через значок в трее. Установка
новой версии поверх прежней использует тот же профиль. Удаление доступно через
«Установленные приложения» Windows. Чтобы оставить настройки и историю,
не отмечать дополнительное удаление данных в окне деинсталлятора.

Сборка из `02_application`:

```powershell
node scripts/compose.cjs build --bundles nsis
node scripts/stage-compose-installer.cjs
```

Результат Tauri: `src-tauri/target/release/bundle/nsis/`. Соседний SHA256 файл в
локальном release-каталоге позволяет проверить конкретный установщик. Публикация
и подпись сертификатом в этой задаче не выполняются.

Изолированная приёмка на чистом пользовательском профиле Windows:

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File scripts/check-compose-installer.ps1 -Installer "<полный путь setup.exe>" -PostmatchReplay "<полный путь replay.SC2Replay>"
```

Скрипт отказывается заменять зарегистрированную Compose-установку. Он устанавливает
в отдельную папку с кириллицей под .compose-test-data, без запуска приложения и
создания ярлыков; сверяет SHA256 всех ресурсов, выполняет native smoke с отдельными
данными, затем удаляет только эту тестовую установку. Отчёт остаётся в test-data.
Личные replay читаются только при явно переданном -PostmatchReplay.

Приёмка28.10: установка в Unicode-путь, SHA256 EXE и 256 ресурсов, настоящий
replay/map HTTP/restart и деинсталляция PASS. Тестовый профиль и отчёты сохранены
под .compose-test-data. Мастер в интерактивном режиме, upgrade рабочего профиля
и bootstrapper на машине без WebView2 остаются отдельными проверками.
