# BRAT_OK — редактируемые исходники Blender

Начать с **[общей сцены v3](scenes/full-scene-v3/BRAT_OK_full_scene_v3.blend)**
или **[библиотеки букв](scenes/alphabet-v1/BRAT_OK_letter_library_v1.blend)**.
Проверенная версия Blender: **5.2.2 LTS**. Все нужные изображения и исторический
шрифт внутри `.blend` упакованы; внешняя библиотека ассетов не требуется.
Blender/MCP, глобальные настройки и платные сервисы не входят в зависимости.

| Каталог в scenes/ | Содержание |
| --- | --- |
| full-scene-v3 | Общий хоровод, 576 кадров, 30 fps, петля 19,2 с |
| alphabet-v1 | Общая сцена + библиотека 53 букв A–Z/a–z/_, примеры, экспорт |
| background-motion-v1 | Фон: волны, дым, купол; актуальная сцена v2 |
| marauder-run-v3 | Самостоятельный цикл мародёра |
| zealot-run-v1 | Самостоятельный цикл зилота |
| hydralisk-slither-v1 | Непрерывный цикл гидралиска |
| zergling-run-v1 | Зерглинг, актуальная сцена v4 |
| ultralisk-v1 | Ультралиск, актуальная сцена v4 |

В отдельных сценах сохранены прежние рабочие этапы. В общей v3 мародёр и зилот
имеют ускоренные циклы 32 кадра вместо 48; остальные темпы сохранены. Ультралиск
по-прежнему перемещается целым рисунком: отдельный шаг лап не реализован.

Рядом со сценами находятся PNG исходной прорисовки, актуальные превью, prompts,
53 готовых прозрачных PNG букв и glyph-metrics.json. Буквы имеют высоту 557 px
и общую базовую линию 432 px. Библиотека видна в Asset Browser → Current File;
не требуется регистрировать её в пользовательских настройках Blender.
`scenes/alphabet-v1/compose_lettering.py` создаёт новые надписи из готовых букв
по явному вызову; автоматически при открытии ничего не выполняется.

## Проверка и рендер

Команды ниже выполнять из этой папки. `blender` должен быть установлен и доступен
в PATH; можно заменить его полным путём к своему Blender. Дополнительный Python
не требуется: инструменты используют Python, входящий в Blender.

```powershell
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/project.py -- audit --report renders/audit.json
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/project.py -- render --file scenes/full-scene-v3/BRAT_OK_full_scene_v3.blend --scene "BRAT_OK — хоровод: четверка и ультралиск" --start 1 --end 576 --percent 50 --report renders/render.json
blender --background --factory-startup --disable-autoexec --python-exit-code 1 --python tools/export_glyphs.py -- --start 0 --end 52
```

Первый вызов проверяет контрольные суммы и открывает все восемь проектов.
Второй явно рендерит все 576 кадров заново, без старого кеша кадров v2.
50% даёт 960×540. Третий заново экспортирует буквы с прозрачностью и метриками.
Результаты всегда пишутся в `renders/`, который исключён из Git.
Сцены при audit/render/export не пересохраняются. Для одного пробного кадра
используйте `--start 1 --end 1`; для одной буквы — `--start 0 --end 0`.

При необходимости MP4 можно собрать установленным FFmpeg из каталога кадров:

```powershell
$frames = "<каталог с frame-0001.png>"
ffmpeg -n -framerate 30 -start_number 1 -i "$frames/frame-%04d.png" -frames:v 576 -c:v libx264 -crf 18 -pix_fmt yuv420p -movflags +faststart "$frames/full-scene.mp4"
```

Готовый GIF, уже используемый приложением, остаётся в
`02_application/src/renderer/assets/smart-overlay/loading.gif` от корня репозитория.
Этот пакет — исходники для редактирования, а не дополнительная runtime-зависимость
и не часть установочного пакета. Внедрение обновлённого рисунка в приложение
требует отдельного явного экспорта/выбора изображения.

## Происхождение и исторические наработки

`migration-sources.json` фиксирует относительные исходные пути, SHA256 оригиналов
и перенесённых файлов. Оригинальные сцены в StarCraft Adjutant не изменялись.
При подготовке копий изменены пути packed-fallback/compositor/render;
для неиспользуемых исторических данных включены fake users, чтобы Blender
не удалял их при сохранении. Рисунки и анимация не редактировались;
параметры сцен и контрольные суммы анимационных кривых проверяются отдельно.
`tools/project.py prepare --allow-save-copies` — служебная явная команда изменения
копий; при обычном редактировании/проверке запускать её не требуется.

`history/` сохраняет прежние build/update/verify/export helpers, layouts, prompts
и отчёты. Скрипты там имеют расширение `.py.txt`: некоторые старые «verify»
пересохраняли сцену, использовали абсолютные пути и промежуточные кадры.
Машинные пути заменены placeholders. Это исторические исходники и доказательства,
не готовая исполняемая сборка. Текущие переносимые команды находятся в `tools/`.
Файлы `HISTORY.md` рядом со сценами также описывают прежние локальные этапы;
актуальный порядок работы задан этим README.

Резервные `.blend1`, `before-*.blend`, отвергнутые варианты, покадровые кеши,
дублирующие ZIP/MP4/GIF и личные настройки MCP/OBS в пакет не включены.
