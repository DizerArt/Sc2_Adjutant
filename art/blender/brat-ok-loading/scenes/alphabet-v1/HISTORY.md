# BRAT_OK — библиотека металлических букв

**53 символа:** заглавные A–Z, строчные a–z и `_`.
Стиль прежнего BRAT_OK: потёртая светлая окраска металла, трещины/сколы,
тёплая фаска и тёмный объёмный край. Рисованные 2D элементы для надписей.

Откройте **BRAT_OK_letter_library_v1.blend**. В нём сохранена общая анимационная
сцена v3 и добавлены три сцены: библиотека всех букв, примеры набора, экспорт.
В Asset Browser выберите **Current File / Текущий файл**: 53 буквы отмечены
как ассеты и снабжены миниатюрами. Их можно перетаскивать в сцену или
дублировать из библиотеки. Начало координат каждой буквы находится на
базовой линии у левого края; ширина естественная, `I/i` уже, `M/m` шире.
Подчёркивание — низкая планка, выносные элементы `Q/g/j/p/q/y` сохранены.
Библиотека не регистрируется в глобальных настройках Blender.

В сцене **«BRAT_OK — примеры набора букв»** уже собраны BRAT_OK, StarCraft
и Loading: каждое слово — группа отдельных букв под общим родителем.
Их можно переносить, масштабировать и использовать как образцы.
Для следующих надписей помощник хранится рядом: **compose_lettering.py**.
Он создаёт экземпляры из библиотеки, поддерживает латинские буквы,
подчёркивание и пробел, регулирует размер/интервалы. В .blend он автоматически
не встраивается и не запускается; безопасный MCP запрещает text datablocks.

**glyphs/** — отдельные PNG с прозрачным фоном. Все имеют одинаковую высоту
557px и baseline432px сверху, ширина соответствует букве. `glyph-metrics.json`
содержит точные размеры, начало координат и advance для программной сборки.
Названия `upper-A.png`/`lower-a.png` различаются на Windows без конфликта регистра.
Исходные рисованные атласы упакованы в .blend; PNG экспортированы нативно
Blender, не вырезаны/перекрашены через Pillow. Локальные исходники не менялись.

Прорисовка выполнена встроенным **image_gen**, без CLI/API-ключа.
Запросы: [заглавные](prompts/uppercase-prompt.txt),
[строчные](prompts/lowercase-prompt.txt),
[исправление интервалов строчных](prompts/lowercase-spacing-v2-prompt.txt).
Первый строчный атлас сохранён в assets/lowercase.png как промежуточный;
библиотека использует исправленный **lowercase-v2.png** и uppercase.png.
Адаптивные UV выделяют каждую букву по прозрачным промежуткам, включая точки.

Проверки и helpers: work/brat-ok-alphabet-v1. Анализ атласов11checks:
53 идентичности по заданному порядку, пустые ячейки/границы/изолированные UV.
Идентичности и стиль дополнительно проверены визуально независимым reviewer;
скрипт не заявляет OCR. Исходные11scene counts/frames сохранены; полного
сравнения всех исходных datablock нет. Первые PNG были подрезаны из-за AUTO
sensor fit на портретном кадре: исправлено на HORIZONTAL, старые рендеры
сохранены в work/rejected-pngs-portrait-fit, конечные PNG/превью перерендерены.
Native/export отчёты фиксируют окончательные проверки отдельно.

элементы и хвостQ не обрезаны. 53 разных рендера, оригиналы атласов побайтно
