# BRAT_OK — отдельный цикл зерглинга

Основной файл: **[BRAT_OK_zergling_gallop_v4.blend](BRAT_OK_zergling_gallop_v4.blend)**.
Активная сцена — «BRAT_OK — зерглинг: галоп». Камера и опорная линия неподвижны.

- [Обычная скорость: MP4](normal.mp4) / [GIF](normal.gif).
- [Втрое медленнее: MP4](slow.mp4) / [GIF](slow.gif).
- [Исходный лист восьми фаз](assets/zergling-gallop.png).

Персонажи готовятся по одному: первым сделан зерглинг, чтобы отдельно оценить
четвероногий бег, опору, толчок и фазу полёта. Восемь рисунков переключаются
по три нативных кадра при 30 кадрах/с: цикл 24 кадра, 0,8с. Обычное видео
повторяет его шесть раз (4,8с), замедленное — два раза по 2,4с (4,8с).

Использован встроенный image_gen с одобренным рисунком зерглинга как референсом.
[Точный запрос](../../../work/brat-ok-zergling-run-v1/prompt.txt).
Копия атласа сохранена без пересохранения. Исходник, одобренные статичные юниты
и прежний фон не перезаписаны. Это восемь полнотелых покадровых рисунков,
не скелетный риг и не раздельные кости конечностей. Две верхние косы остаются
атакующими отростками; движение несут четыре ходильные лапы.

Сетка генератора оказалась неравномерной. В Blender каждой фазе назначена
собственная область UV, одинаковый масштаб пикселей и опорная точка корпуса.
Позиции опорных фаз выровнены, для полётных оставлен зазор над линией земли.
Фазы 7/8 имеют точные многоугольные границы: они сохраняют свой хвост/лапу
и отсекают мелкий соседний фрагмент. Окончательная граница — Y710 в атласе,
по проверке связных компонент, а не промежуточная Y742. Все восемь фаз
не масштабируются отдельно по их bounding box.

Это **первый тестовый цикл для оценки характера движения**. Небольшие
различия головы, панциря и наклона кос между нарисованными фазами сохраняются;
проверять лучше по замедленному ролику. В общую сцену пробега справа налево
этот цикл пока не встроен; другие юниты остаются статичными.

В новом файле сохранены прежние три сцены: исходная 106 объектов, общая
композиция 29, фон 18. Прежняя сцена фона осталась на кадре 118, как перед
началом работы. Отдельный снимок живого состояния —
`work/brat-ok-zergling-run-v1/before-unit-cycle.blend`.
Файлы gallop_v1–v3 — промежуточные, основным является gallop_v4.
В v4 правая граница UV фазы 2 уточнена до X915: независимая проверка обнаружила
мелкий соседний фрагмент косы. Хвост своей фазы сохранён, три кадра перерендерены,
обычный и медленный ролики пересобраны.
Основной агент проверил обновлённый кадр: прежний 18-пиксельный фрагмент
исчез, область совпадает с нейтральным фоном; native assertions v4 прошли.
После восстановления лимита независимый reviewer подтвердил конечную v4:
проект сохранён, атлас встроен, UV-граница X915 и удаление фрагмента проверены.
Блокирующих замечаний нет; характер движения ожидает оценки пользователя.
